# متابعة الراتب

تطبيق أندرويد بسيط وبياناته محلية على الجوال فقط.

## طريقة الحصول على APK
1. أنشئ مستودع جديد في GitHub (Public أو Private).
2. ارفع كل محتويات هذا المجلد (تأكد أن مجلد `.github` انرفع).
3. ادخل تبويب **Actions** وانتظر انتهاء "Build APK" (حوالي 10 إلى 15 دقيقة).
4. حمّل `salary-tracker.apk` من **Releases** (يمين صفحة المستودع) وثبّته على جوالك.
